欢迎使用 **AnZhiYu Astro** —— hexo-theme-anzhiyu 的 Astro 移植版模板。

## 快速开始

三步拥有同款博客：

```bash
# 1. 用模板创建你的仓库（GitHub → Use this template）
git clone https://github.com/<you>/<your-blog>.git
cd <your-blog>

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev
```

打开 `http://localhost:4321`，你将看到与本演示站一致的效果。

## 你可以改什么

- `src/content/` —— 写你自己的文章（Markdown）
- `src/data/` —— 关于页、友链、短文、相册等站点数据
- `theme.config.yml` —— 主题配置（导航、外观、功能开关）
- `public/` —— 静态资源（头像、横幅、图标）
